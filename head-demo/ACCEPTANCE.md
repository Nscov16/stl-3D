# 玩偶头成品网格回读验收

以下仅为随包合成样件数字验证，单位 mm 与 mm³，网格绝对容差 `0.0001 mm`，体积比较容差 `0.01 mm³`；不代表实体制造公差或客户验收。

从独立项目根目录可运行：

```sh
python -IB head-demo/verify_finished.py
```

或完整先装包并运行 `python -IB -m unittest discover -s . -p 'test_*.py' -q`。验收脚本直接回读毛坯和成品 STL，检查成品单一连通闭壳、前脸三角面未变化、加工 Y 端面及 Z=43 上边、上边宽和侧边平面位置。预期前脸面片 6,024；切除体积 4,936.64 mm³；X=0.3 mm 侧剖段内屋顶为 Z=43 mm，段外原毛坯不变。

**待确认**：真实材料/单位/坐标、预期轮廓、实际加工公差及客户 CAD 对照。
